# 使用与维护

配置入口和目录见[安装](installation.md)。业务取决于已启用插件、实际账户权限和当前模型的工具目录。

## 对话与确认

优先直接描述任务，例如“只检查这个项目”“把这三条记录的截止日期改到下周五”“明天下午三点提醒我”。结果使用富文本或卡片，不把内部 JSON 当聊天回执。

原生桌面所有者默认完整权限，inspect/plan 始终只读。飞书仍检查管理员与资源白名单，写入先给冻结预览；可用自然语言同意或拒绝，例如“好的，请修改吧”“好的，请修改把”“可以，就按你说的做”或“这次先别改了”。当前会话模型结合待确认预览识别口语和错别字；普通新问题继续处理，要求改变预览内容则进入对话重做预览。多项待确认须明确指出哪一项；命令只作备用，不要求固定两个字或单独发送命令。业务预览 15 分钟有效，过期需重新生成。

提问卡片可直接选项回答，自由回答用“回答：内容”，多问题用“回答1：内容”。审批和业务确认并存时必须明确选择。提问 5 分钟过期、重启失效，无默认授权；未回答卡片不阻塞新消息，旧答案回原请求，完成结果进入后续上下文。

进度在同一条 Markdown 消息中更新并最终覆盖。webhook 已接收不等于执行或发送成功；执行、上传和投递有独立回执。

## 常用控制

| 命令 | 用途 |
|---|---|
| /help、/status | 当前能力、模型、目录、运行/排队/未知状态 |
| /stop | 停止当前执行，保留排队消息，不撤销已发生的操作 |
| /model、/model provider/model | 查看或切换当前会话模型，不改其他会话 |
| /cd、/cd 绝对路径 | 查看或切目录；飞书限配置 workspace 内真实路径，忙碌时拒绝切换 |
| /new、/reset | 在当前目录新建会话，保留历史和业务数据 |
| /permission、/setting | 查看会话权限和设置，全局设置在官方页面修改 |
| /send 绝对路径 | 发送当前工作区内通过校验的文件 |
| /bitable list、/bases list | 查看已登记表格和 Base；也可自然语言增删 Base 链接 |
| /codex history、/codex read 线程编号 | 本人原生历史；飞书仅限配置的历史所有者私聊 |
| /schedule list、get、history、status | 查询任务、执行及投递记录 |

已知控制命令直接分流，未知斜杠命令返回帮助。切目录创建新会话、不继承旧确认；既有任务仍用创建时冻结的目录和模型。

## 业务规则

- **Codex**：inspect/plan 强制只读；飞书 apply/续聊先确认，仅授权冻结的用户/会话/目录/内容。归档线程只读，不继承历史宽权限。执行上限 20 分钟，Skill 使用冻结运行副本，产物另核验大小与哈希。
- **报告/发布**：报告只新建；发布保持原文正文；Git 单独冻结并授权指定文件、HEAD、分支和远端。覆盖、移动、隔离删除先预览并保留恢复副本，unknown 不重推。
- **自动化**：remind 只提醒；飞书 auto 创建/修改后另需本人执行预授权，confirm 到点逐次确认。原生完整权限可内部授权 auto，显式 confirm 仍按次确认。任务独立执行，修改撤销旧授权。
- **恢复与范围**：skip/run_once/ask 决定迟到处理，weekday 为周一=0，首次时间带时区。授权用户默认可用任意实际存在目录，显式受限原生入口仍受限。stop 只停本次执行，retry-delivery 只恢复待投递或明确失败项。
- **顾问/知识库**：顾问是可选无状态第二意见，不可用时主任务可继续。知识库由上游管理，附件不自动入库。

附件可先发后描述要求，或引用本人同 chat/thread 的附件，暂存 24 小时。文档/出站上限 30 MiB、正文 120,000 字符；图片单张 20 MiB、最多 8 张且合计 30 MiB，受实际 provider 限制。文件校验真实路径、归属、大小及哈希；投递失败不重做业务。

## 备份与恢复

更新/迁移前确认没有运行任务并退出 profile，一起备份 profile 配置、官方 credentials、plugins、sessions、storages 和附件。知识库包括元数据、chunks SQLite、raw 原文及模型配置。依赖/缓存不代替业务数据。

SQLite 使用 backup API，或停机后一并复制主文件及相关 WAL，不能只复制运行中的主 sqlite。备份含凭据，只放在受保护的本机位置，不提交或写入报告。

恢复保持单写者，核对版本、数量、权限和 unknown 后再恢复入口。强制终止后，须等旧渠道租约自然到期再启动，不删除租约来绕过单写者保护。卸载保留数据；代码回退不代表支持数据降级。渠道当前 schema 3，旧代码须配套兼容快照，恢复会舍弃快照后的记录。

## 排障

| 现象 | 处理 |
|---|---|
| 未就绪 | 检查启用状态、设置缺项、精确宿主版本和加载日志 |
| 飞书 403 | 核对来源校验、应用、管理员和卡片归属，不打印凭据/原始事件 |
| 400 / 413 | 检查格式和大小限制 |
| 503 | 检查队列、存储、worker 和并发实例；已接收事件仍去重 |
| 数据库被占用 | 停止另一实例或等崩溃租约过期，不删除数据库绕过 |
| unknown / 丢回执 | 先查会话、业务状态和远端实际结果，不盲目重发、重推或重建 |
| Windows Git file 传输失败 | 可能受官方沙箱 MSYS 管道限制，保留提交状态，不关闭沙箱重推 |

正式启动日志在本机 runtime 的 logs，业务状态在 DSH_HOME。旧日志端口可能过期；从当前官方入口诊断，不公开所有者 URL/token。真实检查见[测试入口](../tests/README.md)，历史发送许可不自动延续。
