## 开始前需要提供

- 仓库外的飞书配置路径已提供，应用/管理员与 Verification Token 已通过存在性预检。需要 AES 时再补 Encrypt Key；密钥不发到聊天、不写入仓库。
- 专用测试 chat 已提供且三项发送已获明确批准。后续用户输入、他人点击/拒绝和 thread 场景仍需限定输入范围及第二个非授权测试用户，不由本次三条授权自动扩张。
- webhook 参考地址为 `https://feishu.windborne.cc/feishu/webhook`，10-31 只读复查仍为 502，已发现本机 3000 没有监听且正式 Web profile 未装 core/feishu。按 [回调指南](feishu-callback.md) 接入；全部使用应用身份，不配置 OAuth 回调。端口保持 3000。UI 保存不会修改隧道/后台，配置页保持本机访问。
- 资源 allowlist：Bitable base/table、docx、wiki 节点、Drive 测试目录、Sheets 精确 range、calendar、tasklist；统一应用凭据引用及允许逻辑能力。
- 应用审核/发布、消息与卡片订阅、实际应用 API scopes 与资源 ACL；配置备用测试数据和清理权限。scope 名称以飞书后台与官方 API 文档当时结果核实，不由逻辑能力字符串推断。
- 测试工作目录、官方 Harness `0.2.1-rc.5`；代码模式复用本机 Codex `0.160.0` 和原生环境，不要求新增账户配置。本轮不配置或验收 OpenCLI 账户；它不是 Codex 前置条件。真实执行/发送仍应明确范围。

先运行不联网预检：

```powershell
$env:TELEBOT_DSH_INSTALL = 'D:/path/to/external-official-install'
pnpm preflight:feishu --reference 'D:/path/outside/repo/local.env' --workspace 'D:/test-workspace'
```

只输出字段存在性、官方版本和准备状态；不打印密钥、不发 API、不启动服务。退出码 2 表示配置未准备好。通过预检仍不能代替以下联调。
